    Tres trabajos propios, en funcionamiento

    Son proyectos míos, no encargos de clientes. Los desarrollé con ayuda de IA (Claude) y me encargué de diseñar las reglas, revisar y probar el resultado.

    Rastreador semanal de subastas públicas

    Recoge cada semana las subastas de varias instituciones (BOE, Seguridad Social, Aduanas y haciendas forales), guarda los lotes en una base de datos y calcula una puntuación de rentabilidad con un modelo de costes. Un panel web permite filtrar y calcular una puja. Se ejecuta solo y envía un resumen por correo. A 15/11/2026 mantenía unos 300 lotes abiertos.

    Hecho con Python, Supabase (PostgreSQL), Next.js y GitHub Actions.

    Buscador de alojamientos con puntuación de calidad y riesgo de estafa

    Busca alojamientos en EscapadaRural y Booking y los puntúa de 0 a 10 por calidad y por riesgo de estafa con reglas explícitas. Fechas, viajeros y presupuesto se cambian desde la propia web. Una búsqueda real devolvió 139 resultados, con filtros, favoritos e historial.

    Hecho con Python, Flask y SQLite.

    Analizador de ideas con la API de Claude

    Escribes una idea de negocio y obtienes un informe estructurado que puedes descargar. Incluye un modo demostración sin clave. Es un ejemplo del tipo de análisis automático de textos que puedo montar para otras personas. Es una demo, no un producto en producción.

    Hecho con Python, Streamlit y la API de Claude.
